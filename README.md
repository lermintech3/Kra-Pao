# Kra-Pap · กระเป๋าเงินของเรา 👛

เว็บแอปวางแผนการเงินและติดตามรายรับ–รายจ่ายของบ้าน สำหรับสองคน หน้าตาแบบ iOS สีสดใส ใช้งานบนมือถือได้ดี

**ใช้งานจริง (ซิงค์ข้อมูลระหว่างสองเครื่อง):** https://claude.ai/artifact/BwTqRXhSnAnvJJAACwtbN3

## ฟีเจอร์
- **หน้าหลัก** – ยอดคงเหลือของเดือน อัตราการออม ใช้เฉลี่ยต่อวัน คาดการณ์สิ้นเดือน ข้อสังเกตอัตโนมัติ
- **กราฟ** – สัดส่วนรายจ่ายตามหมวด, ใครใช้เท่าไหร่ (เรา / แฟน / ร่วมกัน), รายรับ–รายจ่าย 6 เดือน
- **รายการ** – เพิ่ม/แก้/ลบ ค้นหา กรองตามประเภทและคน จัดกลุ่มตามวัน
- **งบ & บิล** – งบรายเดือนต่อหมวดพร้อมแจ้งเตือนเกินงบ, บิลประจำที่กด “จ่าย” แล้วบันทึกรายจ่ายให้อัตโนมัติ
- **เป้าหมายออมเงิน** – ติดตามความคืบหน้า เติม/ถอน คำนวณยอดที่ต้องออมต่อเดือน
- **ความปลอดภัยแบบแอปธนาคาร** – ล็อกแอปด้วยรหัส 6 หลัก (ล็อกอัตโนมัติเมื่อออกจากแอป), ซ่อนยอดเงินเมื่อเปิดแอป
- **กระดิ่งแจ้งเตือน** – บิล/ค่างวดใกล้ครบกำหนดหรือเลยกำหนด, งบใกล้หมด/เกินงบ, คาดว่าสิ้นเดือนติดลบ, เป้าหมายสำเร็จ
- **สลิปรายการ & e-Statement** – แตะรายการดูรายละเอียดพร้อมเลขอ้างอิง, รายการเดินบัญชีรายเดือนพร้อมยอดยกมาและยอดคงเหลือ
- **ตั้งค่า** – ชื่อและอีโมจิของแต่ละคน สำรอง/นำเข้าข้อมูล (JSON)

## การเก็บข้อมูล (เลือกได้ แอปเลือกให้อัตโนมัติ)
1. **Cloudflare D1 (ที่ใช้อยู่)** – ใส่ URL ของ Worker ใน `api-config.js` → เข้าด้วยรหัสบ้าน, ซิงค์ทุก ~8 วินาที
   👉 **วิธีตั้งค่าทีละขั้น: [D1_SETUP_TH.md](D1_SETUP_TH.md)**
2. **Firebase** – ใส่ค่าใน `firebase-config.js` → ล็อกอินด้วย Google ([FIREBASE_SETUP_TH.md](FIREBASE_SETUP_TH.md))
3. **ลิงก์ Claude** – ข้อมูลเก็บในฐานข้อมูลของ artifact (แชร์ให้แฟนด้วยสิทธิ์ Contributor/Editor)
4. **ไม่ได้ตั้งค่าอะไร** – เก็บใน `localStorage` ของเบราว์เซอร์นั้นเท่านั้น

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด |
| `api-config.js` | URL ของ Cloudflare Worker (แก้ไฟล์นี้) |
| `cloudflare/worker.js` | โค้ด Worker — วางใน Cloudflare |
| `cloudflare/schema.sql` | คำสั่งสร้างตารางใน D1 |
| `firebase-config.js` | ค่าเชื่อมต่อ Firebase (ถ้าใช้ Firebase) |
| `firestore.rules` | สิทธิ์ฐานข้อมูล — ใส่อีเมลของคุณกับแฟน |
| `firebase.json` | สำหรับคนที่อยากใช้ Firebase CLI / Hosting (ไม่บังคับ) |

> เรโปนี้เก็บเฉพาะโค้ด ไม่มีข้อมูลการเงินจริงอยู่ในนี้
