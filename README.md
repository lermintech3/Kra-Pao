# Kra-Pap · กระเป๋าเงินของเรา 👛

เว็บแอปวางแผนการเงินและติดตามรายรับ–รายจ่ายของบ้าน สำหรับสองคน หน้าตาแบบ iOS สีสดใส ใช้งานบนมือถือได้ดี

**ใช้งานจริง (ซิงค์ข้อมูลระหว่างสองเครื่อง):** https://claude.ai/artifact/BwTqRXhSnAnvJJAACwtbN3

## ฟีเจอร์
- **หน้าหลัก** – ยอดคงเหลือของเดือน อัตราการออม ใช้เฉลี่ยต่อวัน คาดการณ์สิ้นเดือน ข้อสังเกตอัตโนมัติ
- **กราฟ** – สัดส่วนรายจ่ายตามหมวด, ใครใช้เท่าไหร่ (เรา / แฟน / ร่วมกัน), รายรับ–รายจ่าย 6 เดือน
- **รายการ** – เพิ่ม/แก้/ลบ ค้นหา กรองตามประเภทและคน จัดกลุ่มตามวัน
- **งบ & บิล** – งบรายเดือนต่อหมวดพร้อมแจ้งเตือนเกินงบ, บิลประจำที่กด “จ่าย” แล้วบันทึกรายจ่ายให้อัตโนมัติ
- **เป้าหมายออมเงิน** – ติดตามความคืบหน้า เติม/ถอน คำนวณยอดที่ต้องออมต่อเดือน
- **ตั้งค่า** – ชื่อและอีโมจิของแต่ละคน สำรอง/นำเข้าข้อมูล (JSON)

## การเก็บข้อมูล
- เปิดผ่านลิงก์ Claude (ล็อกอิน) → ข้อมูลเก็บในฐานข้อมูลของ artifact และซิงค์แบบเรียลไทม์ระหว่างสองคน
  (แชร์ให้แฟนด้วยสิทธิ์ **Contributor** หรือ **Editor**)
- เปิดไฟล์ `index.html` ตรง ๆ → ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์นั้นเท่านั้น

> เรโปนี้เก็บเฉพาะโค้ด ไม่มีข้อมูลการเงินจริงอยู่ในนี้
